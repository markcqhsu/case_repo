## 案例標題
國內COA 自動建立

## 案例摘要
國內出貨時需附上檢驗報告書（COA）。過去需將倉儲出貨資訊手寫於出貨表，再人工登打至 EIP 系統產生 COA；現在改為將出貨資訊輸入出貨表後，由自動化程式直接生成 COA，省去重複登打，提升出貨文件作業的效率與正確性。

## 問題背景
國內出貨需附上檢驗報告書（COA）。過去的作業方式是先到倉儲拍照記錄出貨資訊，再手寫在出貨表上，最後到 EIP 系統人工逐筆登打產生 COA。各產品每天平均需花費約 45 分鐘登打，日期、數量及備註欄位也曾發生錯字；到了生產旺季出貨量大時，登打與核對所需的時間更多，人力負擔明顯增加。

## 核心問題
COA 需經手寫與人工重複登打才能產出，作業耗時且容易出錯，難以因應旺季大量出貨需求。

## 解決方案
同仁將倉儲出貨資訊輸入 Excel 出貨表後，由 Python 自動化程式讀取表中的產品名稱、製造日期與數量，並以 IRP 系統每日稽核填入的檢驗數據為基礎，自動登入 EIP 系統生成 COA（PDF），取代原本手寫及人工登打的流程。

## 執行流程
- 至倉儲拍照記錄出貨資訊
- 將出貨資訊（製造日期、數量）輸入 Excel 出貨表
- 執行 Python 自動化程式，讀取出貨表資料
- 程式比對 IRP 系統中對應的每日稽核檢驗數據
- 程式自動於 EIP 系統建立 COA 並生成 PDF
- 同仁確認 COA 內容

## 主要功能
- Excel 出貨資料輸入｜同仁只需將製造日期、數量輸入熟悉的 Excel 出貨表，不需學習新系統
- 檢驗數據自動帶入｜程式自動比對 IRP 系統的每日稽核檢驗數據，不需人工查找與抄寫
- EIP 自動建立 COA｜程式自動登入 EIP 系統建立 COA，取代人工逐筆登打
- PDF 自動生成｜自動產出 COA PDF 檔，可直接用於出貨

## AI 的應用方式
- 使用 Claude 協助撰寫與除錯 Python 自動化程式

## 使用工具
- Excel｜出貨表，同仁輸入製造日期與數量的資料來源
- Python｜自動化程式，負責讀取出貨表、比對檢驗數據並操作 EIP 系統
- IRP 系統｜提供每日稽核的檢驗數據，作為 COA 內容的基礎
- EIP 系統｜建立 COA 並生成 PDF 的公司內部系統
- Claude｜協助撰寫與除錯 Python 自動化程式

## 執行成果
- 已正式上線，應用於宏全一廠與二廠國內出貨的 COA 作業
- 每日 COA 產出時間從各產品平均約 45 分鐘的人工登打，縮短為程式自動執行約 3～5 分鐘，時間節省約九成
- 減少日期、數量、備註等欄位的人為錯字
- 旺季出貨量大時，不再需要額外投入大量登打與核對時間

## 產生價值
- 對品保同仁｜省去手寫與重複登打，每天可省下大量時間投入其他品質管理工作
- 對客戶｜COA 資料正確性提升，出貨文件更即時、可靠
- 對公司｜降低人為錯誤與人力成本，旺季出貨也能穩定產出 COA，並建立可複製的文件自動化模式


## 可複製與延伸應用
- 可應用於其他需要從 Excel 資料登打至 EIP 系統的表單作業

## 使用限制與注意事項
- 出貨表需維持固定的欄位格式，輸入的製造日期與數量需正確，否則會影響 COA 內容
- IRP 系統當日的稽核檢驗數據需先完成填寫，程式才能正確帶入
- EIP 或 IRP 系統的畫面、欄位或登入方式如果有更新，程式可能需要跟著調整
- 程式產出的 COA 仍需同仁確認內容後才能隨貨出貨

## 成功關鍵
不改變原有作業習慣，透過 Python 程式串接 IRP 檢驗數據與 EIP 系統，將最耗時、最容易出錯的人工登打全面自動化，並藉由 Claude 協助開發，讓品保單位也能自行完成程式建置與維護。
