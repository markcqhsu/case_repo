## 案例標題
LINEBOT 應用 : 推播功能與資料即時查詢

## 案例摘要
建立兩種 LINE Bot 應用架構：方案一為 LINE Bot 搭配 n8n，依排程或文字關鍵字觸發，主動推播工作待辦提醒、會議提醒、每日工作回報，並可查詢班表與電話分機表；方案二為 LINE Bot 搭配雲端資料庫，透過互動式選單並整合 LLM 語言模型，讓使用者即時查詢產品異常排除等資料，系統自動回覆可能原因、對策建議與參考圖片。

## 問題背景
品保單位過去仰賴人工在 LINE 群組手動整理並發送工作提醒、會議通知、每日工作回報，也需要有人隨時待命回覆班表、電話分機及產品異常排除等查詢。隨著查詢量增加，人工發送與逐一回覆的方式耗費大量時間，也容易發生提醒漏發或回覆延遲的情況。

## 核心問題
如何讓 LINE Bot 依排程或關鍵字自動推播提醒與回報，並讓使用者可透過文字或選單即時查詢班表、聯絡資訊及產品異常排除建議，減少人工整理與逐一回覆查詢的時間。

## 解決方案
整體規劃為兩個互補的方案：

方案一（LINE Bot 搭配 n8n，主動推播）：先在資料夾建立文字或圖片等原始資料（excel、word、jpg 等格式皆可），再透過 n8n 工作流設定判斷機制，依「定時」或「文字觸發」兩種方式運作。定時推播可用於工作待辦提醒、會議提醒及每日工作回報；文字觸發則用於查詢班表、電話分機表及表定工作事項，使用者只要在群組輸入指定格式的關鍵字（例如「問＋時間＋(課別/產品)＋(班別)」），機器人便會自動查詢並回覆結果。

方案二（LINE Bot 搭配雲端資料庫，資料即時查詢）：先將文字與圖片資料建立至雲端資料庫，使用者透過互動式選單（依產品類別，例如塑蓋、鋁蓋、爪蓋、PET 瓶）點選欲查詢的項目，並整合 LLM 語言模型於雲端資料庫中搜尋，自動回覆可能原因、對策建議，並附上參考圖片。

## 執行流程
- 方案一：於資料夾建立文字／圖片等原始資料。
- 方案一：於 n8n 設定工作流的判斷機制（定時或文字觸發）。
- 方案一：時間到達時自動推播工作待辦提醒、會議提醒或每日工作回報。
- 方案一：使用者輸入指定關鍵字格式，觸發機器人查詢班表、電話分機表或表定工作事項並回覆。
- 方案二：於雲端資料庫建立文字／圖片資料。
- 方案二：使用者透過互動式選單依產品類別點選欲查詢的項目。
- 方案二：LINE Bot 整合 LLM 語言模型，於雲端資料庫中搜尋對應資料。
- 方案二：機器人自動回覆搜尋結果，包含可能原因、對策建議及參考圖片。

## 主要功能
- 定時推播｜依排程自動推播工作待辦提醒、會議提醒與每日工作回報，無需人工手動發送。
- 文字觸發查詢｜使用者輸入指定格式關鍵字，即可查詢班表、電話分機表及表定工作事項。
- 互動式選單查詢｜依產品類別點選查詢異常排除資訊，不需要輸入文字。
- LLM 智慧回覆｜整合語言模型於雲端資料庫中搜尋，自動回覆可能原因與對策建議，並附上參考圖片。
- 雙軌架構彈性運用｜依情境選擇 n8n 主動推播或雲端資料庫即時查詢，可單獨或搭配使用。

## AI 的應用方式
- 使用 LLM 語言模型理解使用者輸入的查詢文字並比對雲端資料庫內容
- 依據異常關鍵字自動歸納可能原因與對策建議
- 協助設計 n8n 工作流的判斷邏輯與訊息格式

## 使用工具
- LINE Bot｜作為使用者互動介面，接收訊息並推播、回覆查詢結果
- n8n｜設定自動化工作流，處理定時推播與文字觸發判斷
- 雲端資料庫｜儲存文字與圖片資料，供互動式選單與 LLM 搜尋使用
- LLM 語言模型｜理解查詢內容並自動生成搜尋回覆

## 執行成果
- 主動推播工作待辦提醒、會議提醒與每日工作回報，減少人工手動發送訊息的時間。
- 使用者可透過文字關鍵字即時查詢班表、電話分機表及表定工作事項。
- 透過互動式選單即可查詢產品異常排除建議，不需要另外翻閱文件或詢問其他同仁。
- 導入 LLM 語言模型後，查詢回覆可包含可能原因分析與具體對策建議，並附上參考圖片。

## 產生價值
- 對品保人員｜減少手動整理與逐一回覆查詢的時間，同仁可直接透過 LINE 取得所需資訊。
- 對現場人員｜可隨時透過 LINE 查詢班表、聯絡資訊及異常排除建議，不需等待專人回覆。
- 對公司｜將原本分散於個人經驗與人工回覆的知識整合進雲端資料庫與自動化流程，方便後續維護與擴充應用。

## 可複製與延伸應用
- 其他部門的工作提醒與會議通知推播
- 各類表單、規範或作業指南的即時查詢
- 設備異常排除或維修知識庫查詢
- 客服或內部問答機器人

## 使用限制與注意事項
- 雲端資料庫內容需持續更新維護，才能確保 LLM 回覆的正確性
- n8n 工作流的定時與觸發規則需依實際需求調整，避免誤觸發或漏發
- 屬輔助查詢與提醒工具，實際異常排除仍須由專業人員確認

## 成功關鍵
將原本分散在各同仁記憶與人工整理中的排班、聯絡及異常排除知識，整合進雲端資料庫與自動化工作流，並透過 LINE Bot 提供即時、一致的推播與查詢管道。
