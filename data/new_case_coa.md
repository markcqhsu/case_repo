## 案例標題
COA 製作與寄送自動化流程

## 案例摘要
透過 Python 與 n8n 建立 COA 自動化流程，將原本需要人工整理出貨資料、製作 COA 及逐封寄送郵件的作業，整合成標準化流程。品保人員完成出貨資料確認後，系統可自動產生 COA，並依照客戶資料夾及收件人清單，自動判斷寄送對象、加入副本收件人及寄出對應的 COA，減少重複操作時間。

## 問題背景
COA 製作與寄送原本包含多項人工操作。品保人員需要先到倉儲確認出貨日期及數量，再將出貨資料輸入指定檔案，製作對應的 COA。完成後，還需要依不同客戶查找收件人、確認副本對象、建立郵件並逐一寄送。當出貨批次或客戶數量增加時，這些重複作業會占用較多時間，也容易因人工輸入、檔案分類或收件人設定錯誤，造成 COA 資料或寄送內容不正確。

## 核心問題
如何將 COA 的資料整理、文件產生、客戶判斷及郵件寄送流程標準化，減少品保人員重複輸入與逐封寄送郵件的時間。

## 解決方案
整體流程分為兩個部分：

COA 製作自動化：品保人員確認出貨日期及數量後，透過 Python 將出貨單轉換成系統可讀取的格式，並將出貨資訊整理至指定檔案中。系統再根據整理後的出貨資料，自動產生對應的 COA，減少人工逐份製作文件的作業。

COA 寄送自動化：先建立包含客戶關鍵字、主要收件人及副本收件人的清單，並依照客戶名稱分類待寄送的 COA。品保人員只需要將 COA 放入指定位置，設定本次出貨日期及寄件人後執行 n8n 工作流。系統便會自動讀取檔案、判斷對應客戶、查找收件人清單，並將 COA 寄送給正確的客戶及相關人員。

## 執行流程
- 人員確認出貨日期及出貨數量。
- 使用 Python 轉換出貨單格式。
- 將出貨資訊整理至指定資料檔案。
- 使用 Python 自動產生 COA。
- 將待寄送的 COA 依客戶分類。
- 系統讀取客戶與收件人對照清單。
- 執行前設定出貨日期及寄件人。
- 啟動 n8n 自動化工作流。
- 系統判斷客戶並配對收件人。
- 自動附加 COA 並寄送郵件。

## 主要功能
- 將出貨資料自動轉換並產生 COA。
- 支援多個客戶與多份 COA 批次處理。
- 依客戶名稱自動判斷對應收件人。
- 支援主要收件人與多位副本收件人。
- 自動將正確的 COA 附加至對應郵件。
- 透過 n8n 工作流完成批次郵件寄送。
- 保留出貨日期與寄件人等執行參數，方便不同批次使用。

## 執行成果
- 自動產生符合出貨資料的 COA。
- 將 COA 製作與郵件寄送整合成標準化流程。
- 減少人工製作及逐封寄送郵件的時間。
- 降低收件人、附件與出貨資料配對錯誤的風險。
- 支援不同產品類別及不同寄件帳號。
- 收件人清單建立完成後，可持續重複使用。
- 讓批次 COA 寄送作業更有效率且容易交接。

## 產生價值
- 對品保人員｜減少重複輸入資料、製作文件、查找收件人及逐封寄送郵件的時間，只需要完成出貨資訊確認及執行前參數設定，即可處理整批 COA。
- 對業務與客戶｜客戶可以更快速且穩定地收到正確的 COA，降低因附件錯誤、收件人錯誤或漏寄所造成的溝通問題。
- 對公司｜將原本依賴個人經驗的作業方式轉換成標準化自動流程，提升作業效率、降低人為錯誤，並讓後續教育訓練與工作交接更加容易。

## 使用限制與注意事項
- 出貨日期與數量是否正確
- COA 內容是否符合實際檢驗結果
- 客戶資料夾名稱是否與收件人清單一致
- 收件人及副本資料是否為最新資訊
- 待寄送的附件是否放置在正確位置
- 本次使用的寄件帳號與產品類別是否正確
- 此流程主要協助文件製作及寄送作業，不取代品保人員對產品檢驗結果及 COA 內容正確性的專業確認。
- 若新增客戶、更換聯絡人或調整郵件規則，需同步更新收件人清單，避免郵件寄送錯誤。
