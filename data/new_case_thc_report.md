## 案例標題
訂單與財務智慧分析平台（THC Report）

## 案例摘要
整合集團訂單資料（OCR 辨識的紙本／PDF 訂單、SAP 直接匯出的訂單 Excel）與財務資料（月度損益、季度合併財務報表），建立一個管理層可以直接查看銷售、毛利、客戶與產品結構的儀表板平台，取代原本分散在各業務單位 Excel、紙本與口頭回報的彙整方式。

## 案例分類
內部管理工具、數據儀表板、業務與財務分析

## 問題背景
集團訂單資料原本分散在各業務單位（國內業務、業三部出口、飲料代工、東南亞、大陸等）各自的紙本或 PDF 訂單、Excel 報表中，財務數據則來自每月／每季的損益與合併財報文件。管理層若要掌握集團整體的銷售、毛利、客戶或區域表現，需要向各單位分別索取報表再手動彙整比對，耗時且容易因格式、幣別、匯率換算不一致而失真。

## 核心問題
如何在同一個平台整合來自不同來源（OCR 辨識的紙本訂單、SAP 直接匯出的訂單 Excel、季度合併財報）、不同幣別、不同業務單位分類邏輯的資料，讓管理層可以即時查看集團與各單位的訂單、客戶、產品、毛利表現，不必依賴人工彙整。

## 解決方案
以 Cloudflare Workers + D1 建立的訂單與財務分析平台，分為三大模組：
- 訂單分析（依業務單位）：國內業務、業三部（出口）、飲料代工、東南亞、大陸各自的 Dashboard，透過 OCR 辨識訂單 PDF 自動建立結構化訂單資料，並依各業務單位幣別特性採用「不跨幣別加總」或「換算基準幣別後加總」兩種安全的金額呈現邏輯，避免不同幣別的金額被誤加總
- 集團訂單分析：直接讀取 SAP 訂單匯出 Excel，建立集團總覽、區域分析、客戶分析等頁面，用公司匯率設定將各幣別換算成報表幣別後彙總，並提供客戶價值矩陣、重點客戶排行榜等進階分析
- 財報分析：解析月度損益 Excel 與季度合併財務報表，建立損益分析、趨勢分析、損益結構、合併財務總覽等頁面

## 執行流程
- 依各業務單位／集團訂單／財報三大模組分別設計資料表結構與匯入邏輯
- 訂單 PDF 上傳後，透過 OCR 辨識並比對既有客戶／產品資料，自動建立或更新訂單，並標示疑似重複的訂單供人工確認
- SAP 集團訂單 Excel 上傳後，依欄位規則解析並比對地區、部門、公司代號主檔，直接寫入資料庫，用來源編號避免重複匯入
- 建立公司匯率設定機制，將各幣別訂單換算為報表幣別後計算銷售金額與加權毛利率
- 依管理層回饋逐步擴充頁面（如客戶分析的客戶價值矩陣、重點客戶排行榜）並持續修正資料正確性
- 每次新增功能皆先在 Cloudflare Workers 的 preview 版本上，用測試帳號完整驗證資料正確性後才部署到正式環境

## 主要功能
- 訂單 OCR 上傳｜上傳紙本或 PDF 訂單，自動辨識並建立結構化訂單資料，具重複訂單偵測
- 各業務單位 Dashboard｜國內業務、業三部、飲料代工、東南亞、大陸各自的銷售／毛利／客戶／產品圖表分析
- 集團總覽｜跨業務單位的集團層級 KPI、依區域／公司銷售金額、訂單類型分布
- 區域分析｜台灣／大陸／東南亞／非洲各區域的銷售趨勢、部門或公司佔比、佔集團比重
- 客戶分析｜客戶價值矩陣（銷售金額 × 毛利率泡泡圖）、重點客戶排行榜、客戶產品組合、客戶與公司／區域關係
- 集團訂單查詢｜可篩選、搜尋、直接編輯任一筆訂單資料
- 財報分析｜月度損益分析、趨勢分析、損益結構，以及季度合併財務報表總覽
- 公司匯率設定｜管理者可維護各幣別對報表幣別的公司匯率，供跨幣別金額換算使用
- 使用者權限管理｜依財報／訂單權限分別授權，控管各單位可見範圍

## AI 的應用方式
- 使用 OCR／AI 辨識紙本或 PDF 訂單內容，自動擷取客戶、產品、數量、金額等欄位並比對既有主檔資料
- 全程使用 Claude Code 進行開發：從資料庫 Schema 設計、Excel／PDF 解析邏輯、頁面與圖表設計、除錯到部署驗證，皆由 Claude 以對話方式與需求方共同完成，並在瀏覽器中即時操作驗證畫面正確性後才上線

## 使用工具
- Claude Code｜全程協助程式開發、資料庫設計、除錯與功能規劃
- Cloudflare Workers｜應用程式部署與執行環境
- D1（SQLite）＋ Drizzle ORM｜資料庫與資料存取層
- React Router（Framework Mode）｜前端框架
- Cloudflare R2｜儲存上傳的訂單／財報原始檔案
- ECharts｜圖表視覺化

## 執行成果
- 集團訂單分析已匯入實際 SAP 訂單資料（累計超過 600 筆訂單、188 家客戶、20 家集團公司）
- 建立集團與各區域、各客戶、各業務單位的即時銷售與毛利率分析，取代人工彙整報表
- 客戶價值矩陣等進階分析協助識別核心客戶、潛力客戶與需關注客戶
- 平台持續依管理層回饋快速迭代，同一天內可完成多次功能新增、修正並部署上線

## 產生價值
- 對總管理處／管理層｜可即時查看集團與各業務單位的訂單、客戶、毛利表現，不需再向各單位個別索取報表彙整
- 對數位發展部｜建立一套可持續擴充的資料整合與分析架構，作為後續集團數位化的基礎
- 對各業務單位｜訂單資料建立後即可共用於多個分析角度，減少重複的報表製作工作

## 可複製與延伸應用
- 產品分析、毛利分析等尚未完成的集團訂單分析頁面可依相同架構持續擴充
- 匯率設定與資料整合架構可延伸至其他跨幣別、跨單位的集團管理需求
- OCR 訂單辨識機制可複製到其他仍以紙本／PDF 為主要單據形式的業務流程

## 使用限制與注意事項
- 部分訂單資料的成本尚未於 SAP 登入完成，計算毛利率時會排除，並提示未計入筆數，避免毛利率失真
- 各業務單位的金額換算需管理者手動維護匯率設定，尚未串接即時匯率
- OCR 辨識訂單仍需人工確認，非全自動流程
- 目前僅供集團內部管理層與相關單位使用，需帳號權限才能存取

## 成功關鍵
針對不同資料來源（OCR 紙本訂單／SAP 匯出 Excel／財報文件）建立各自對應但一致的匯率換算與資料驗證邏輯，並在每次功能上線前，於獨立的測試環境用真實資料驗證正確性後才部署，確保管理層看到的數字經得起檢驗。
