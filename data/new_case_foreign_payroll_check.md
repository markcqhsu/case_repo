## 案例標題
外籍員工薪資清冊離線比對工具

## 案例摘要
運用 AI 協助開發 Windows 離線工具，將國稅局「申報單位各類所得清冊」PDF 與財務薪資 Excel 自動比對，列出所得人代號、姓名及金額差異，並辨識缺漏、重複與待人工確認項目。工具提供繁體中文介面與可追溯報表，協助財務同事集中處理異常資料；所有比對均在本機完成。

## 問題背景
外籍員工薪資分為每月 10 號及 15 號發放，財務需要核對各批次所得清冊與 Excel 薪資資料。原有 Python 原型以 OCR 讀取圖片 PDF，辨識品質不足，且操作方式需要程式環境，不便讓一般財務同事使用。後續確認電子申報系統可透過「印表機設定 → 名稱 → Microsoft Print to PDF」另存文字版 PDF，已有七月清冊成功比對的實際案例。

## 核心問題
需要正確識別員工、核對給付日期與所得月份，並區分真正差異、缺漏及讀取不確定情況。圖片辨識可能造成錯字與誤判，檔名日期也不能直接視為內容日期，因此工具必須保留來源與原值，讓財務能回查確認。

## 解決方案
建立以文字版 PDF 為主要來源的 Windows 離線工具，唯一以 PDF「統一編（證）號」與 Excel「居留證號」配對。核對完整日期後，10 號批次對應 P1，15 號批次對應 P2，再比較姓名、所得人代號、所得、稅額與淨額。圖片版或含無可用文字頁面的 PDF 會在讀取員工前提示並停止，說明如何從電子申報系統另存文字版。財務發佈包內含 Python 執行環境與必要依賴，不攜帶 OCR 元件。

## 執行流程
- 從電子申報系統以 Microsoft Print to PDF 另存對應批次的所得清冊。
- 選擇薪資 Excel、結果資料夾與一份或多份 PDF；薪資工作表自動讀取，多個符合的表才需要選擇。
- 檢查 PDF 文字層，核對完整給付日期、所得月份及 P1／P2 對應，日期不明或衝突時提示確認。
- 依居留證號配對，逐欄比較姓名、所得人代號及該期三個金額，檢查缺漏與重複。
- 匯出批次摘要、差異與待確認項目、完整比對 CSV 及摘要 JSON，供財務回查來源。

## 主要功能
- 多批次比對｜支援多份 PDF，依 10 號／15 號及完整年月日區分薪資批次。
- 唯一證號配對｜以居留證號識別員工，姓名與所得人代號作為配對後的比較欄位。
- 差異與缺漏檢查｜列出姓名、代號、金額不一致，以及 Excel 或 PDF 單邊缺漏。
- 重複與不確定資料標示｜保留同批次重複證號、空白、無法讀取與日期不明等待確認項目。
- 金額與文字正規化｜金額以數值比較；文字統一全半形，姓名連續空白縮為一個，保留原值。
- 可追溯報表｜保留 Excel 序號、工作表與列號，以及 PDF 檔名、頁碼和兩邊原值。
- 繁體中文操作｜提供選檔、進度與結果介面，財務操作不需輸入命令。
- 本機離線處理｜不修改來源 Excel／PDF，不上傳資料，不呼叫外部 API。

## AI 的應用方式
- 使用 Codex 協助把財務需求整理成可驗證的配對、日期、金額與異常處理規則。
- 協助檢查及修改既有 Python 原型，建立文字 PDF 讀取、比對報表與繁體中文介面。
- 依測試回報與打包記錄定位錯誤，補充回歸測試並修正 Windows 建置流程。
- 協助產出離線打包工具、操作說明與驗證記錄；實際薪資比對由本機程式依明確規則執行。

## 使用工具
- Codex｜需求整理、程式開發、測試、除錯與文件撰寫。
- Python／Tkinter｜本機比對邏輯與繁體中文桌面介面。
- PyMuPDF｜直接擷取 PDF 文字及欄位位置。
- openpyxl｜讀取 Excel 薪資資料，保留欄位、公式快取狀態與來源位置。
- PyInstaller｜製作包含執行環境與必要依賴的 Windows 發佈包。
- Microsoft Print to PDF｜從電子申報系統另存可供工具讀取的文字版清冊。

- 已建立正常資料、代號錯誤、金額錯誤、雙向缺漏、重複、空白與零值等回歸測試。
- 四月圖片版測試確認整體辨識不足，據此改為先提示不適用並引導取得文字版。
- 已移除主畫面的工作表及列號進階輸入，使用者回報新版介面測試成功。
- 已提供雙擊離線打包入口，使用者回報 Windows 打包成功；成品真實資料操作與無 Python 電腦驗證仍待完成。

## 產生價值
- 對財務單位｜減少逐筆查找與核對工作，將注意力集中在差異及待確認項目。
- 對公司｜建立一致的核對規則與可追溯紀錄，降低批次混用、漏查及人工操作錯誤的風險。
- 對使用同事｜透過繁體中文介面完成選檔與比對，發佈包設計為不需另裝 Python 或 Tesseract。

## 可複製與延伸應用
- 延伸至其他月份及相同版面的所得清冊核對。
- 將唯一識別碼配對、批次日期核對與來源追溯模式，應用於其他 PDF／Excel 資料核對作業。
- 依後續需求擴充其他所得類別或清冊版面，新增對應規則及驗證樣本。

## 使用限制與注意事項
- 本版以文字型 PDF 為使用前提；圖片版或含無可用文字頁面的 PDF 會提示並停止。
- Microsoft Print to PDF 必須從電子申報系統原始清冊列印；既有圖片 PDF 重新列印不會自動轉成文字。
- 測試及正式比對需使用給付日期與所得月份相互對應的 PDF 與 Excel；檔名日期僅作提示。
- 待人工確認項目需要回查原始檔，總額相同不能作為逐筆一致的證明。
- Excel 該期三個金額皆為確定的數值零時，免列 PDF 缺漏；空白或讀取失敗不能當成零。
- 成品需保留 exe 旁的 _internal 資料夾；無 Python 電腦的實際操作驗證尚待完成。
- 尚未量測實際節省工時與導入後的錯誤率，效益描述為預期改善。

## 成功關鍵
由財務提供對應月份的實際資料與 Windows 操作回饋，逐步釐清配對規則和使用方式；確認圖片 OCR 的限制後，改採可取得的文字 PDF，並透過保留原值、來源位置與人工確認機制，讓自動比對結果可被核查。
